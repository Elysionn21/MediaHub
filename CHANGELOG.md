# MediaHub 0.2.0

## What's new
- Added the system tray menu and automatic per-user Start Menu shortcut.
- Fixed startup crash during shortcut creation.
- Added settings for language and download folder, with Downloads as the default.
- Improved clipboard link handling and VLC playback for supported streaming URLs.
- Added GitHub release update checks and verified in-app updates.

## Download
Download `MediaHub.exe` from the v0.2.0 release assets. Windows 10/11 64-bit is required. VLC is needed for playback; yt-dlp is downloaded by the app when missing.
